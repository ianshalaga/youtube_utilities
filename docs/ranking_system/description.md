# Ranking System

## Modelo de Datos

- Un Player pertenece a un único Country.
- Un Country puede tener cero o muchos Players.
- Un Player puede tener cero o muchos alias.
- Un alias pertenece a un único Player.
- Un Player puede tener cero o muchas cuentas sociales.
- Cada cuenta social pertenece a un único Player.
- Un Event se juega en una única Platform.
- Una Platform puede tener cero o muchos Events.
- Un Event se juega en una única versión del juego.
- Una versión del juego puede tener cero o muchos Events.
- Un Game tiene una o más versiones.
- Una GameVersion pertenece a un único Game.
- Una identidad de personaje puede existir en múltiples juegos/versions.
- Un GameCharacter refiere a una única identidad base.
- Una versión del juego puede tener cero o muchos personajes.
- Un GameCharacter pertenece a una única versión del juego.
- Una Season puede contener cero o muchos Events.
- Un Event puede pertenecer opcionalmente a una Season.
- Un Event contiene uno o más Duels.
- Un Duel pertenece a un único Event.
- Un Duel tiene dos o más participantes.
- Un DuelParticipant pertenece a un único Duel.
- Un DuelParticipant representa a un Player.
- Un Player puede participar en muchos Duels.
- Un Duel se compone de una o más Battles.
- Una Battle pertenece a un único Duel.
- Una Battle enfrenta exactamente a dos participantes.
- Un BattleParticipant pertenece a una única Battle.
- Un BattleParticipant representa a un Player.
- Un Player puede participar en muchas Battles.
- Un BattleParticipant usa un único GameCharacter.
- Un GameCharacter puede ser usado en muchas Battles.
- Una Battle se compone de uno o más Rounds.
- Un Round pertenece a una única Battle.
- Un Round produce exactamente dos resultados.
- Cada RoundResult pertenece a un único Round.
- Un RoundResult corresponde a un Player.
- Un Player puede tener muchos resultados de Round.
