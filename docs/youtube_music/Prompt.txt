Genera un JSON exhaustivo de una saga de videojuegos siguiendo estas reglas estrictas:

1. COBERTURA DE LA SAGA

* Incluye TODOS los juegos del universo de la saga:

  * juegos principales
  * secuelas
  * precuelas
  * remakes y remasters
  * spin-offs (incluyendo móviles, arcade y ports relevantes)
  * expansiones (si aplican, especialmente en MMORPGs)
* Ordena los juegos estrictamente por fecha de lanzamiento (ascendente)

2. ÁLBUMES
   Para cada juego, incluye TODOS los álbumes conocidos relacionados con su banda sonora:

* OST oficiales (SIEMPRE primero)
* Álbumes oficiales adicionales:

  * arrangement
  * piano collections
  * vocal albums
  * drama albums
  * compilaciones oficiales
* Álbumes no oficiales:

  * gamerips
  * fan rips
  * reconstrucciones

3. ESTRUCTURA DE CADA ÁLBUM
   Cada álbum debe tener EXACTAMENTE esta estructura:

{
"is_official": true | false,
"type": "OST | Arrangement | Piano | Vocal | Compilation | Drama | Gamerip | Other",
"album": "Nombre oficial del álbum",
"vgmdb_url": "URL o null",
"khinsider_url": "URL o null",
"archive_url": "URL o null",
"khinsider_candidates": ["lista de URLs plausibles"],
"archive_candidates": ["lista de URLs plausibles"]
}

4. REGLAS DE ORDEN

* Dentro de cada juego:

  1. is_official = true (primero)
  2. is_official = false (después)
* Dentro de cada grupo:

  * OST primero
  * luego el resto por relevancia

5. FUENTES
   Cruza información de:

* KHInsider (descargas)
* Internet Archive (backup/fallback)
* VGMdb (fuente principal de metadata)

6. VALIDACIÓN

* NO inventes URLs verificadas
* Si no es seguro → usar null
* Usa candidates para posibles coincidencias
* Mantén nombres de álbum lo más oficiales posible

7. FORMATO

* Respuesta SOLO en JSON válido
* Sin explicaciones fuera del JSON
* Mantener consistencia en naming y estructura

8. CALIDAD

* Prioriza exactitud sobre cantidad cuando haya duda
* Evita duplicados
* Usa nombres canónicos de juegos y álbumes

Ahora genera el JSON para la saga: [NOMBRE_DE_LA_SAGA]
